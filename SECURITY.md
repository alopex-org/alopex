# Security policy

FoxieOS hardware holds research documents only.
There is no device, firmware or software of its own to report against yet.

- Report a problem in the FoxieOS operating system under [FoxieOS's security policy](https://github.com/alopex-org/foxieos/blob/main/SECURITY.md).
- If a document here could lead someone to damage a device or expose a key, for example through a wrong fusing or relocking step, don't describe it in a public issue.

**Planned before any device from this project is sold:**

- A private reporting contact will be listed here.
  Until then, don't report security problems in public issues.
- A process for coordinated disclosure.
  The EU's Cyber Resilience Act requires a device's manufacturer to report actively exploited vulnerabilities ([docs/FEASIBILITY.md](docs/FEASIBILITY.md#eu-cybersecurity-rules)).
